# eCommerce-Plugins-Payment-Aggregator-Gateway-Indonesia-PAGI-
Payment Gateway Indonesia untuk Virtual Account, QRIS, DANA, OVO via BDPay Open API. 
Plugin resmi-style untuk menerima pembayaran di CMS Pilihan Anda menggunakan BDPay.

**Version:** 1.0  
**Developer:** Wiriasto © 2026  
**License:** GPL-2.0-or-later

Plugin / modul pembayaran untuk toko online Indonesia:
- Virtual Account (BCA, Mandiri, BNI, BRI)
- QRIS
- e-Wallet (DANA, OVO)

Powered by BDPay Open API.

## CMS yang didukung
- WooCommerce
- OpenCart
- Bagisto
- PrestaShop
- Magento 2
